Download and Installation

Stable Sartre 2 source

The public Sartre 2 source is available from the Sartre GitHub repository. This repository contains the latest stable version only. Development is carried out elsewhere, so the GitHub repository should be treated as a stable distribution source rather than a development branch.

To download the source with Git, open a terminal and run:

git clone https://github.com/tobiastoll/sartre.git
cd sartre

Alternatively, use the repository's Code button on GitHub and choose Download ZIP. Unpack the archive and change into the resulting sartre directory before continuing.

Requirements

Sartre is developed and tested on macOS and Linux. A C++17 compiler and CMake 3.30 or newer are required. The core library also requires:

  • ROOT, including the MathMore and Unuran components;
  • the GNU Scientific Library (GSL).

Inclusive-diffraction event generation is enabled by default in Sartre 2 and additionally requires Pythia 8. If only the exclusive library is needed and Pythia 8 is unavailable, inclusive diffraction can be disabled at CMake configuration time. Boost is needed only for the optional multithreaded build.

Configure, build, and install

Use an out-of-source build. From the top-level Sartre source directory:

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
cmake --install build

By default, installation is under /usr/local/sartre. Select another prefix when configuring the build if needed:

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=/path/to/install

If CMake cannot find ROOT, GSL, or Pythia 8, configure their normal installation prefixes or environment setup before running CMake. The exact variables depend on how those packages were installed. Read CMake's configuration messages carefully; do not continue to the build step if a required dependency was not found.

Exclusive-only build

To build without the inclusive-diffraction event-generation components and therefore without Pythia 8:

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DENABLE_INCLUSIVE_DIFFRACTION=OFF
cmake --build build
cmake --install build

Optional multithreaded build

Table generation can use the optional multithreaded build. This requires Boost and should be enabled only when needed:

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DMULTITHREADED=ON

Build the example programs

Set SARTRE_DIR to the installed Sartre directory, then configure the supplied examples in a separate build directory. For an installation at the default prefix:

export SARTRE_DIR=/usr/local/sartre
cmake -S "$SARTRE_DIR/examples" -B build_examples
cmake --build build_examples

The examples include sartreMain for exclusive diffraction and UPC, and sartreInclusiveDiffractionMain for inclusive diffraction. The latter requires that the library was installed with ENABLE_INCLUSIVE_DIFFRACTION=ON, which is the default.

Installing tables

Sartre event generation requires precomputed ROOT tables. They are large and are distributed separately from the source repository through the Sartre table server. A source checkout or installation therefore does not necessarily contain the table set required for a particular calculation.

The installed getSartreTables.py utility downloads a published table bundle and unpacks it into the correct directory below the installation's tables/ directory. Always run the copy installed in Sartre's bin/ directory; do not copy the script to another location. It discovers the Sartre installation from its installed path, so it also works when sudo removes SARTRE_DIR from the environment. List the catalog with:

$SARTRE_DIR/bin/getSartreTables.py list

Select a table set with its collision system, dipole model, particle or process, and parameter set. Selection is case-insensitive. The catalog can be listed without administrator permission, but a system-wide installation normally requires sudo to install files. For example, to install exclusive φ-meson tables for electron–lead collisions with the bSat model:

sudo $SARTRE_DIR/bin/getSartreTables.py \
  --sys=ePb --sat=bSat --part=phi --set=KMW

The default selection is a non-UPC table set. Add --upc to request a UPC set. Use --part=X for inclusive-diffraction tables, for example:

sudo $SARTRE_DIR/bin/getSartreTables.py \
  --sys=ePb --sat=bSat --part=X --set=KMW

An explicitly set SARTRE_DIR overrides automatic discovery and is intended only for a deliberate installation override or development use. If no matching bundle is published, the utility stops without changing the installation and recommends getSartreTables.py list. It also refuses to overwrite existing table files. Use --help (or -?) for the complete command reference. The resulting hierarchy must be preserved; see Tables and Table Tools for the directory layout and table-inspection guidance.
