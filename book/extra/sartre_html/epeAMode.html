ep and eA Modes

Sartre uses the same small-x dipole framework for electron-proton (ep) and electron-nucleus (eA) scattering. The target differs: an ep calculation uses a proton profile, while an eA calculation represents a nucleus as a fluctuating configuration of nucleons. This makes eA diffraction sensitive to both the average spatial gluon distribution and its event-by-event fluctuations.

Selecting the target

The runcard setting A selects the target mass number:

A = 1       # proton target: ep
A = 197     # nuclear target: eA, for example gold
A = 208     # nuclear target: eA, for example lead

A table set must exist for the selected mass number and all other requested physics settings. The table hierarchy begins with this value, for example tables/1/... for a proton and tables/197/... for a nucleus. See Tables and Table Tools.

Proton targets: ep

With A = 1, Sartre models scattering from a proton. In exclusive diffraction it generates vector-meson production or DVCS from the impact-parameter-dependent dipole amplitude. Proton tables contain the precomputed amplitude information needed for the chosen dipole model, parameter set, and process.

Proton scattering is also the baseline for nuclear calculations. In particular, Sartre uses compatible proton information when it evaluates the real-amplitude and skewedness corrections for an eA run. Consequently, a nuclear table set alone may not be sufficient when either correction is enabled.

Nuclear targets: eA

With A > 1, Sartre constructs the target from a nuclear configuration. Nucleon positions are sampled from a Woods-Saxon distribution; deuterium is handled with a Hulthén distribution. The sampled configuration is recentered before it is used to construct the transverse nuclear density. Optional subnucleon structure adds hot-spot fluctuations within each nucleon.

The nuclear extension is not a simple multiplication of a proton cross section by A. The dipole interacts with the transverse distribution of nucleons, so nuclear geometry, multiple scattering, and saturation affect the result. The larger nuclear gluon density makes eA scattering a particularly useful setting for studying nonlinear small-x dynamics.

Coherent and incoherent diffraction

For a nuclear target, exclusive diffraction has two experimentally and physically distinct components:

Mode
Target response and physics sensitivity
Coherent The nucleus remains intact. The cross section is calculated from the squared configuration-averaged amplitude and probes the average transverse gluon distribution.
Incoherent The nucleus changes configuration or dissociates. The cross section is the variance of the amplitude over configurations and probes fluctuations of the nuclear and, when enabled, subnucleon structure.

If enableNuclearBreakup = true, Sartre can pass an incoherently excited nucleus to the Gemini++ breakup model and add the stable breakup products to the event record. This option is meaningful only for nuclear targets, increases the run time, and is disabled for UPC mode.

Inclusive diffraction in ep and eA

Sartre 2 extends both target modes to inclusive diffractive DIS:

e + p/A → e' + p'/A' + X

The SartreInclusiveDiffraction interface selects the inclusive workflow. It uses bSat/IPsat or bNonSat/IPNonSat amplitudes and includes the qq̅ and qq̅g contributions. Inclusive runs require compatible inclusive tables when useInclusiveCrossSectionTables = true; these are stored in the X process directory described in the table documentation.

Practical checklist

  1. Set A to 1 for ep or to the desired nuclear mass number for eA.
  2. Select a compatible dipoleModel, dipoleModelParameterSet, and process.
  3. Install the matching table set under $SARTRE_DIR/tables.
  4. For eA exclusive runs with real-amplitude or skewedness corrections enabled, also ensure that matching proton tables are present.
  5. For inclusive diffraction, start from examples/sartreInclusiveDiffractionRuncard.txt and check the β, Q2, W, and z ranges against the supplied tables.
