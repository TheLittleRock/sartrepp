double L(double, double, double) const

Evaluates the longitudinal photon overlap for deeply virtual Compton scattering at the supplied coordinates.

double mf2() const

Returns zero because the DVCS overlap does not use a vector-meson quark-mass parameter.

Detailed Description

Photon wave-function overlap implementation for deeply virtual Compton scattering. It supplies the transverse and longitudinal overlap functions appropriate to the real-photon final state.
