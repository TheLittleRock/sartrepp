Detailed Description

Amplitudes calculates gamma-A d sigma/dt ingredients for transverse and longitudinal photons. It returns average amplitudes, average squared amplitudes, numerical coherent amplitudes, errors, and values needed for skewedness corrections. The FFT methods calculate values for all Delta grid points in one call for nuclear targets.
