Destroys the writer and closes any open output file.

bool open(string, bool breakupOn = false)

Opens the named eic-smear output file and writes its header. Set breakupOn to include nuclear-breakup information.

bool writeEvent(Event*)

Writes the supplied Sartre event in eic-smear format and returns whether writing succeeded.

void close()

Closes the current output file.

bool hasOpenFile() const

Returns whether an output file is currently open.

string filename() const

Returns the filename of the current or most recently opened output file.

Detailed Description

Writes generated events in the eic-smear format. Open a destination, pass generated Event records to writeEvent(), and close the writer when generation is complete.
