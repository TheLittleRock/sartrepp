Detailed Description

Table stores generated amplitude/cross-section table data and provides interpolation over the stored axes. Sartre 2 supports classic exclusive three-dimensional tables, UPC two-dimensional tables, inclusive-diffraction four-dimensional tables, and an exclusive FFT variant with user-supplied t-bin edges. Tables can be filled programmatically, written to ROOT files, read back, queried, listed, and optionally backed up while being filled.
