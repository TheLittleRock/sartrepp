Enumeration Documentation

enum DipoleModelType

Selects the dipole model implementation: bSat, bNonSat, or bCGC.

enum GammaPolarization

Selects transverse or longitudinal virtual-photon polarization.

enum AmplitudeMoment

Identifies the stored amplitude quantity in tables: mean amplitude, mean squared amplitude, variance, and lambda values for real-amplitude and skewedness corrections.

enum DiffractiveMode

Selects coherent or incoherent diffraction.

enum DipoleModelParameterSet

Selects a named dipole-model parameter set, or CUSTOM. Exact numeric values are configured elsewhere. TBD: full parameter table.

enum TableSetType

Describes whether table sets store total/coherent tables or coherent/incoherent tables.

enum FockState

Selects inclusive-diffraction Fock-state contribution: QQ, QQG, or ALL.

Detailed Description

Defines the small set of global selector types used throughout the library: dipole model and parameter-set choices, photon polarization, amplitude moment, diffraction mode, table-set layout, and inclusive Fock state.

Legacy Sartre 1 notes and examples

These enumerations are used throughout Sartre to identify the dipole model used, the polarization of the virtual photon, and the diffractive mode. Names are self-explanatory. AmplitudeMoment is used to identify and distinguish tables and is mostly for experts.
