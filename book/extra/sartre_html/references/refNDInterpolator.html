Constructs an interpolator from grid iterators, grid lengths, and function-value iterators. Data are copied when CopyData is true.

Reference-counted constructor variant. It initialises the grids and function array, stores N grid reference-count objects, and stores the function-array reference-count object.

void set_f_array(IterT f_begin, IterT f_end, bool bCopy)

Stores function values in C-order. Throws std::invalid_argument if the number of values does not match the grid shape.

void set_f_refcount(ArrayRefCountT& refF)

Stores the function-array reference-count object.

int find_cell(int dim, T x) const

Returns the lower grid-cell index for coordinate x in dimension dim. Returns -1 below the grid and the last grid index above the grid.

T get_f_val(const array<int, N>& cell_index, const array<int, N>& v_index) const

Returns the stored function value at a cell vertex, clamping outside-grid cell indices to boundary values.

T get_f_val(const array<int, N>& cell_index, int v) const

Returns the stored function value for vertex number v.

Detailed Description

General N-dimensional interpolation wrapper used by table access. It owns or references grid data and dispatches to the selected interpolation method for a requested coordinate vector.
