bool generate(int A, Event* event, FockState state)

Builds/afterburns the inclusive final state for target mass number A, writing to event. state selects QQ or QQG content. Returns success.

Detailed Description

Builds inclusive diffractive final states from the sampled kinematics and selected Fock state. It populates the Event particle record, including the partonic/hadronic products used by the inclusive workflow.
