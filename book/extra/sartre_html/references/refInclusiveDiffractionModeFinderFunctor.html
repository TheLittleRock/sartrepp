InclusiveDiffractionModeFinderFunctor(InclusiveDiffractiveCrossSections* cs, double Q2, double W2, double z, double MX2min, double MX2max)

Constructs the functor from an inclusive cross-section object and fixed kinematic variables. MX2min and MX2max bound the diffractive-mass scan.

double DoEval(double x) const

Uses x as MX2. It returns zero outside the configured mass range; otherwise it evaluates the inclusive cross section and returns its negative so ROOT minimisation finds the maximum.

void setQuarkMass(double mq)

Sets the quark mass used in the inclusive-diffraction scan.

ROOT::Math::IGenFunction* Clone() const

Returns a heap-allocated copy through the ROOT function interface.

Detailed Description

Functor used during inclusive event generation to select the diffractive contribution or mode. It adapts inclusive cross-section information to the numerical sampling machinery.
