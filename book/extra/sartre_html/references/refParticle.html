Data Member Documentation

int index

Zero-based index of this particle in Event::particles. In the standard Sartre event record, index 0 is the incoming electron and index 1 is the incoming hadron. The index uniquely identifies the particle within the event.

int pdgId

Particle Data Group identifier. Nuclei and heavy fragments use the nuclear PDG form 10LZZZAAAI, where L is the number of strange quarks for a hypernucleus and I is the isomer level (0 for the ground state). For example, the gold ion is encoded as 1000791970.

int status

Status follows the HepMC conventions used by the legacy documentation:

  • 0 — unused entry with no meaningful information.
  • 1 — final-state particle that is not decayed further by the generator.
  • 2 — decayed hadron, tau or muon, or intermediate virtual particle.
  • 3 — documentation entry.
  • 4 — incoming beam particle.
  • 11--200 — other intermediate particles.

Sartre currently uses status values 1, 2, and 4.

TLorentzVector p

Four-momentum with respect to the beam axis. The electron beam travels with negative pz, while the hadron beam travels with positive pz. For nuclei, momentum and energy are expressed per nucleon.

vector<int> parents

Indices of the parent particles in Event::particles. Sartre currently has at most two parents for a particle.

vector<int> daughters

Indices of the daughter particles in Event::particles.

Detailed Description

Particle is a lightweight public record for one particle in an Event. It has no member functions and all its data members are public. The record stores a unique event index, status, four-momentum, and parent/daughter relationships expressed as indices into the event particle vector.

For nuclei, the event-record four-momentum is expressed per nucleon. See the individual data-member entries for the supported status values, nuclear PDG encoding, and beam-axis convention.

Legacy Sartre 1 notes and examples

The Particle class contains all information needed to describe any particle used in Sarte. The particles are stored in an internal list in the Event class. It is a lightweight class without any member functions and all data members are public. The data members hold information on the particle's status (stable/decayed), 4-momentum, parent particle(s), daughter particle(s). Each particle is uniquely identified by an index number.

Note that moment and energy (TLorentzVector p) for nuclei are always expressed as per-nucleon.
