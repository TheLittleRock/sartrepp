Detailed Description

CrossSection evaluates exclusive vector-meson/DVCS cross sections from Sartre tables. It supports the usual ep/eA variables t, Q2, and W2, and UPC variables t and xpom. The main functor returns total cross sections and records which polarization and diffractive mode were used for the last accepted call.
