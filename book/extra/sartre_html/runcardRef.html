Runcard Reference

A runcard is a plain-text settings file read during initialization. It configures the event generator or a table-generator program without recompiling the application. The same settings can be set programmatically through Settings, EventGeneratorSettings, and TableGeneratorSettings.

Each non-comment line has the form name = value but name : value is also accepted. Lines beginning with # or //, and blank lines, are ignored. Boolean values accept true/false, yes/no, and on/off.

Examples

The shipped files examples/sartreRuncard.txt, examples/sartreInclusiveDiffractionRuncard.txt, and examples/tableGeneratorInclusiveDiffractionRuncard.txt are the most reliable starting points. Copy one, make only the changes needed for the intended calculation, and retain it with the generated output for reproducibility.
